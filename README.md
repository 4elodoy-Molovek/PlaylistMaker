# Playlist Maker

Учебное Android-приложение для поиска музыкальных треков.

## Возможности

- Главный экран и навигация между поиском, настройками и деталями трека.
- Поиск по названию и исполнителю без учёта регистра.
- Локальный Storage эмулирует источник данных с задержкой три секунды.
- Состояния начального экрана, загрузки, результатов и ошибки.
- Очистка запроса отменяет текущий поиск и убирает результаты.
- Тёмная тема с сохранением выбора.
- Системный обмен, письмо разработчику и открытие пользовательского соглашения.

## Сборка

Используются Android Studio 2026.2.2, Android SDK 37.0 и Build Tools 36.0.0.
Gradle Wrapper 9.4.1 и Android Gradle Plugin 9.2.0 входят в конфигурацию проекта.
Gradle запускается на встроенной в Android Studio Java. Минимальная версия Android — API 24.

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Укажите путь к установленному SDK в локальном файле local.properties.
4. Запустите приложение на эмуляторе или Android-устройстве.

Команды для Windows:

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:lintDebug
```

Отладочный APK находится в app/build/outputs/apk/debug/app-debug.apk.

## Архитектура

- domain содержит модель трека и интерфейс репозитория.
- data содержит Storage и реализацию репозитория.
- ui содержит Compose-экраны, SearchViewModel и состояния поиска.
- di связывает зависимости через Koin.

UI получает результаты через StateFlow. Репозиторий выполняет поиск на Dispatchers.IO.
Каждый новый поиск отменяет предыдущий. Отмена корутины обрабатывается отдельно от ошибок.

## Проверка

Для проверки поиска введите yesterday или BEATLES и нажмите лупу.
Должны отобразиться загрузка, затем найденные треки с длительностью mm:ss.
Запрос xyzmissing показывает пустую выдачу. Крестик очищает поле и результаты.
Нажатие на трек открывает детали, кнопка «Назад» возвращает к результатам.

Адрес разработчика и ссылка на соглашение задаются ресурсами developer_email и agreement_url.
